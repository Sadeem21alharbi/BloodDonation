> **A smart, fast, and secure blood donation experience in Saudi Arabia.**

---

## 📌 Project Overview
**Project Name:** Ehyaa Platform  
**Project Description:**  
Ehyaa is a specialized technical platform designed to bridge the gap between blood donors and hospitals. By leveraging modern web technologies, the platform aims to transform blood donation into a seamless digital culture. It facilitates the saving of lives by providing a reliable database for blood types and urgent donation requests, ensuring speed, transparency, and data security within the Saudi healthcare ecosystem.

---

## ✨ Features List
- **User Management:** Secure registration for donors with profile management for blood types and locations.
- **Urgent Request System:** Real-time posting and browsing of urgent blood donation needs.
- **Smart Dashboard:** An intuitive interface for users to track their donation history and upcoming eligibility.
- **Notification Engine:** Localized alerts to notify donors when their specific blood type is needed nearby.
- **Interactive Map:** Integration to help users locate the nearest hospitals and donation centers.
- **Responsive Design:** Fully mobile-optimized interface ensuring accessibility across all devices.
- **Bilingual Support:** Full support for both Arabic and English languages.
